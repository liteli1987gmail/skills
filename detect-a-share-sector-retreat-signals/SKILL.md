# A股板块撤退信号

## 目标

用可复核的日线价格和成交额识别风险撤退阶段。优先回答：

1. 标的是权重龙头、情绪龙头还是双重属性龙头。
2. 最早在哪个交易日满足哪一种信号。
3. 信号依据的成交额基准是否代表当前上涨周期。
4. 公开数据能证明什么，不能证明什么。

只研究风险识别时，不用清仓后的收益率评价信号，不把“后来上涨”当作否定退出纪律的证据。

## 强制工作流

### 1. 先做标的消歧

- 核对公司全称、证券代码、交易所、曾用简称和当前简称。
- 股票简称或代码冲突时，停止行情解释，先完成消歧。
- 标明数据截止日期、复权方式和成交额来源。

### 2. 先完成硬分类，再计算因子权重

按信号发生时的市场作用分类，不把产业地位直接等同于权重，不把类型当成永久标签：

- **权重龙头**：必须有可核验的主要指数权重、显著自由流通市值或板块核心定价权证据。公司产业重要、产品稀缺或属于细分龙头，不足以单独归为权重。
- **情绪龙头**：不满足权重门槛，且属于小中市值、高弹性、高换手或题材情绪中心。优先识别两日高成交额崩塌。
- **双重属性**：必须同时满足权重证据与情绪高弹性证据。不能因为“既有产业、又会涨停”就轻易使用。

分类必须给出当时的指数权重、自由流通市值、板块相对规模和价格弹性依据。无法证明权重时，默认降级为情绪型或“用户选定的高关注标的”，不要用“产业锚”替代权重证据。

### 3. 使用差异化因子权重

权重表示该因子对该类型公司的决策强度，不是统计学习结果：

- `1.00`：主清仓因子，满足后才能作为该公司的主撤退结论；
- `0.70–0.99`：次级预警，单独列出最早出现时间，但不能覆盖或冒充权重1.00的主撤退结论；
- `<0.70`：状态确认，只说明风险阶段，不能单独形成撤退结论。

| 因子 | 权重龙头 | 情绪龙头 | 双重属性 |
|---|---:|---:|---:|
| 两日高成交额崩塌 | 0.85 | **1.00** | **1.00** |
| 三日高成交额撤退 | **1.00** | 0.90 | **1.00** |
| 两日严重承接坍缩 | 0.45 | **1.00** | **1.00** |
| 两日承接坍缩 | 0.45 | 0.80 | 0.75 |
| 持仓钝化／承接衰退 | 0.20 | 0.35 | 0.30 |
| 未归类价格崩塌 | 0.10 | 0.20 | 0.15 |

解释顺序：

- 权重龙头重点看机构容量下的持续高成交额撤退，三日持续性权重最高。
- 情绪龙头一旦出现两日高成交额崩塌，直接视为最高权重撤退信号，不等待第三日。
- 情绪龙头有两条同级撤退路径：高成交额踩踏与严重承接坍缩，任一满足即为权重1.00。
- 情绪龙头的一般两日承接坍缩是0.80次级预警，不能替代任一权重1.00的主撤退因子。
- 双重属性并行采用高成交额与严重承接坍缩两个主因子，一般承接坍缩只作次级预警。
- 同时输出“最早次级预警”和“首个1.00主撤退信号”。用户问最终结论时，以首个1.00信号为准；用户问最快风险暴露时，再补充更早预警。

### 4. 确定上涨周期成交额基准

不得机械使用固定60日上涨日均额。

基准优先级：

1. 从最近一轮明确上涨周期起点到首次大跌前，计算其中上涨日的平均成交额。
2. 上涨周期起点不清楚时，使用首次大跌前20个交易日中上涨日的平均成交额。
3. 样本不足才使用60日上涨日均额，并同时报告20日基准及二者差异。

若20日上涨日均额比60日基准高20%以上，标记“成交额状态切换”。此时禁止只用60日基准下结论。

同时报告：

- 当日成交额；
- 相对当前上涨周期上涨日均额的倍数；
- 相对前20日全体交易日均额的倍数；
- 与前一交易日成交额相比是增加还是减少。

只在相对当前周期确有放大时使用“放量”“高成交额崩塌”等措辞。比例来自陈旧低基准时，明确撤销该标签。

### 5. 识别候选退出信号

设首次大跌日收益率为 `r1`，当前上涨周期上涨日均成交额为 `A_up`。

#### 两日高成交额崩塌

- 第一天跌幅不低于5%；
- 连续两个交易日收跌；
- 两日累计跌幅不低于10%；
- 两日成交额均不低于 `A_up`。

第二日收盘确认。只有对应权重为1.00时才能成为主撤退结论。

若只达到 `A_up` 附近，不写“快速放大”；只有显著高于当前周期基准或日间继续增加时才写“放大”。

#### 两日承接坍缩

- 第一天跌幅不低于5%；
- 连续两个交易日收跌；
- 两日累计跌幅不低于10%；
- 第二日成交额低于 `A_up`；
- 第二日成交额低于第一日。

第二日收盘确认。它对情绪与双重属性属于次级预警，对权重龙头属于状态预警。

#### 两日严重承接坍缩

先满足两日承接坍缩的价格条件：

- 第一天跌幅不低于5%；
- 连续两个交易日收跌；
- 两日累计跌幅不低于10%。

再满足以下任一成交额结构：

1. **递减式承接消失**：第一日成交额低于 `A_up`，第二日不高于 `0.70 × A_up`，且第二日较第一日至少下降20%；
2. **持续低承接**：两日成交额均不高于 `0.70 × A_up`，且第二日不高于第一日。

第二日收盘确认。它对情绪型与双重属性股票权重为1.00；对权重龙头仍只作辅助预警。一般承接坍缩继续使用原权重，不得全部升级。

#### 三日高成交额撤退

- 第一天跌幅不低于5%；
- 连续三个交易日收跌；
- 三日成交额均不低于 `A_up`。

第三日收盘确认。若此前只有0.70–0.99的预警，仍继续寻找首个1.00主撤退信号；不得让较早低权重事件覆盖较晚主因子。

### 6. 识别第二阶段状态

#### 持仓钝化／承接衰退

- 第一天跌幅不低于5%；
- 至少连续两个交易日收跌；
- 确认日成交额低于下跌前20个交易日的全体日均成交额。

这是风险状态确认，不自动取代更早的正式清仓信号。它说明交易活跃度和承接下降，不等于止跌。

### 7. 处理未分类的价格崩塌

如果两日累计跌幅不低于10%，但成交额：

- 既未明显高于当前上涨周期均值；
- 第二日也未低于第一日；

则标记为**正常成交额水平下的价格崩塌／价格风险预警**。不要为了让所有案例落入既有因子而强行分类。

### 8. 输出最早节点

按以下顺序报告：

1. 首日跌超5%的风险触发日；
2. 公司类型及首个权重1.00的主撤退信号；
3. 主撤退确认日和下一交易日；
4. 主撤退之前最早出现的0.70–0.99次级预警；
5. 权重低于0.70的状态确认；
6. 后续重复主信号仅作为阶段验证。

## 解释边界

- 高成交额连续下跌支持“大量筹码持续交换或主动撤退”，不能单凭行情证明卖方一定是机构。
- 缩量连续下跌支持“承接和交易意愿下降”，不能证明持有人都不理智或都相信一定会涨回来。
- 缩量不等于抛压安全释放，更不等于止跌。
- 成交额基准、龙头身份和信号确认是三个独立问题，不能相互替代。
- 不提供个性化买卖指令；输出研究规则、历史信号和可证伪条件。

## 数据与脚本

优先使用含真实成交额的日线数据，不以成交量代替成交额。BaoStock可用时运行：

```bash
python scripts/scan_retreat_signals.py \
  --stocks 奥海科技=sz.002993=emotion 华虹宏力=sh.688347=weight \
  --start 2025-08-01 \
  --end 2026-07-30
```

脚本默认使用前20个交易日上涨日均成交额，并同时输出20日全体均额和60日上涨日均额，用于发现基准漂移。缺少 `baostock` 时在临时虚拟环境安装，不污染用户项目环境。

需要理解规则修正、反例和用户质疑时，读取 [references/challenges-and-corrections.md](references/challenges-and-corrections.md)。

先给结论表：

|---|---|---|---:|---|---|---|

再逐只说明：

- 分类依据；
- 首日及连续下跌幅度；
- 每日成交额和正确基准倍数；
- 为什么属于该信号；
- 是否存在更早预警、后续重复信号或无法归类的价格崩塌；
- 数据和推断边界。
