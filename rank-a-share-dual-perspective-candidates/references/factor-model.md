# 双视角因子模型

## 0. 因子归类

| 类别 | 典型字段 | 正向解释 | 逆向解释 | 是否倒置 |
|---|---|---|---|---|
| 数据质量与可交易性 | 来源、日期、覆盖率、停牌 | 决定证据能否使用 | 同左 | 否 |
| 价格—成本结构 | 现价、平均成本、成本偏离 | 站上成本、套牢压力小 | 深度低于成本、悲观充分 | 是 |
| 筹码状态 | 获利盘、70%/90%集中度 | 盈利筹码多且成本集中 | 低获利盘、成本分散 | 是 |
| 行为确认 | 事件后收益、量价承接、相对强弱 | 趋势修复与资金承接 | 尚弱、等待止跌触发 | 是 |
| 基本面事件 | 盈利、扭亏、预亏、预告修正 | 盈利改善或利空被价格吸收 | 坏消息集中、预期极低 | 有限倒置 |
| 情境标签 | 行业、题材、市场风格、估值 | 解释分数和拥挤度 | 解释错杀或风格逆转 | 默认不计分 |
| 硬风险 | 退市、重大违法、偿债/持续经营危机 | 剔除或单列 | 同样剔除或单列 | 否 |

“完全逆向”只针对同一组连续型收益预测因子。不能把缺失数据、造假风险、停牌或退市风险机械翻译成正贡献。

## 1. 原始字段

| 字段 | 含义 |
|---|---|
| `closePrice` | 筹码快照对应收盘价 |
| `chipAvgCost` | 推算的筹码平均成本 |
| `chipProfitRate` | 当前价格以下的筹码占比，0至100 |
| `chipConcentration70` | 70%筹码成本集中度，越低越集中 |
| `chipConcentration90` | 90%筹码成本集中度，越低越集中 |
| `postEventReturnPct` | 事件日至分析截止日收益率 |
| `volumeSupportScore` | 按统一规则评估的量价承接分，0至100 |
| `earningsStatus` | 最新相关报告期的业绩预告状态；聚合源空结果未经官方核验时使用`no_forecast_unverified` |
| `tradeable` | 截止日是否可交易；只有明确为`true`才通过门槛 |
| `hardRisk` | 是否触发不可倒置硬风险；只有明确为`false`才通过门槛 |
| `riskFlags` | 退市、违法、持续经营、偿债等风险原因数组 |
| `reversalTrigger` | 逆向名单是否已有止跌触发；无法取得事件行情时保持缺失，不得写成`false` |

成本偏离：

```text
costGapPct = (closePrice / chipAvgCost - 1) × 100
```

## 2. 正向评分

将原始因子映射至0至1。`scale(x,a,b)`表示把`a`映射为0、`b`映射为1，并在区间外截断。

| 因子 | 权重 | 正向映射 |
|---|---:|---|
| 成本位置 | 20 | `scale(costGapPct,-35,10)` |
| 获利盘 | 20 | `chipProfitRate / 100` |
| 筹码集中 | 15 | `1-scale(C70,10,35)`；缺C70时用`1-scale(C90,15,45)` |
| 事件后修复 | 15 | `scale(postEventReturnPct,-15,15)` |
| 量价承接 | 15 | `volumeSupportScore / 100` |
| 业绩状态 | 15 | 使用下表 |

业绩映射：

| 状态 | 分值 |
|---|---:|
| `profit`、`turnaround` | 1.00 |
| `increase` | 0.90 |
| `positive_decrease` | 0.60 |
| `no_forecast` | 0.50 |
| `mixed` | 0.25 |
| `loss` | 0.00 |
| `unknown`或字段缺失 | 不参与 |

`no_forecast`必须来自成功完成的官方公告检索。东方财富初筛无记录使用`no_forecast_unverified`，按`unknown`处理，不参与评分。

只对可用因子加权并重新归一化：

```text
positiveScore = 100 × Σ(weight × mappedValue) / Σ(availableWeight)
coverage = Σ(availableWeight) / 100
```

覆盖率低于60%、筹码核心字段少于两个，或`tradeable`/`hardRisk`未完成明确核验时不进入正式排名。

## 3. 完全逆向评分

逆向模型不得更换样本、日期或数据源：

```text
reverseScore = 100 - positiveScore
```

因此逆向模型系统性偏好：深度低于成本、低获利盘、分散筹码、事件后弱势、承接不足和预亏。

逆向分数衡量悲观程度，不衡量止跌确认。正式输出分为：

- `reverseRanking`：完整的逆向相对排序；
- `reverseWatchlist`：达到最低分数门槛但未确认止跌；
- `reverseTriggered`：达到最低分数门槛且`reversalTrigger=true`。
- `reverseUnassessed`：达到分数门槛但历史行情缺失，无法判断止跌；不得并入“未触发”观察池。

默认正向和逆向候选最低分数均为60。可以显式调整，但报告必须披露门槛；无人达标时返回空名单。`reverseTriggered`仍然只是研究观察条件，不是买入确认。

## 4. 量价承接分

没有统一成交额字段时不得主观填分。取得事件窗口后按下列证据给分：

| 证据 | 建议区间 |
|---|---:|
| 事件后继续放量创新低 | 0至25 |
| 下跌量未收缩、价格无修复 | 25至45 |
| 成交趋稳但方向不明 | 45至55 |
| 下跌缩量、不再创新低 | 55至70 |
| 上涨日放量且收复事件跌幅 | 70至85 |
| 放量突破平均成本并产生行业超额收益 | 85至100 |

记录评分证据。缺少事件后数据时保持缺失，不使用50分静默填充。

## 5. 正向组合解释

### 趋势修复

```text
costGapPct >= 0
chipProfitRate >= 50
C70较低
postEventReturnPct > 0
```

解释为多数筹码进入盈利、平均成本已收复。注意获利兑现风险。

### 利空消化

```text
earningsStatus = loss
但costGapPct >= 0
且postEventReturnPct > 0
```

解释为已知利空可能被计价。必须核对公告是否早于价格修复，不能把时间先后写反。

### 低位稳定

```text
chipProfitRate低
C70较低
下跌缩量
不再创新低
```

只能称为稳定候选；集中筹码也可能是锁仓套牢。

### 预亏但相对走强

```text
earningsStatus = loss
公告后不再创新低
postEventReturnPct和行业超额收益为正
量价承接改善
```

正常分析师可推断利空被部分吸收，但仍需拆分主营亏损、减值、股份支付等原因，不能仅凭“亏损已知”得出反转结论。

## 6. 逆向组合解释

### 最大套牢压力

```text
costGapPct <= -20
chipProfitRate <= 25
C70较高
```

逆向模型认为悲观充分；正向模型认为上方解套压力大。

### 基本面与技术双重悲观

```text
earningsStatus = loss
costGapPct < 0
chipProfitRate低
postEventReturnPct < 0
```

只有出现止跌触发才从观察池转为触发名单。

### 失败风险

持续经营恶化、亏损来自主营而非一次性减值、现金流紧张、解禁减持或行业趋势继续向下时，低估值和低获利盘可能长期维持。

## 7. 组合冲突矩阵

| 组合 | 正向模型 | 逆向模型 | 输出处理 |
|---|---|---|---|
| 高获利盘＋站上成本＋放量修复 | 趋势确认 | 拥挤且赔率下降 | 正向候选，提示兑现风险 |
| 低获利盘＋深度低于成本＋继续放量下跌 | 破位与抛压 | 悲观充分但未止跌 | 仅逆向观察池 |
| 低获利盘＋下跌缩量＋不创新低 | 趋势仍弱 | 卖压衰竭 | 满足门槛时进入逆向触发 |
| 预亏＋公告后相对走强 | 利空消化 | 悲观因子仍在但价格不再确认 | 两种解释并列，核对时序 |
| 预亏＋主营恶化＋现金流紧张 | 基本面负面 | 可能是价值陷阱 | 硬风险门槛，不因逆向分数升级 |
| 热门题材＋筹码分散＋高换手 | 催化与弹性 | 拥挤交易风险 | 题材作标签，不单独决定名单 |

## 8. 时间一致性

分别建立：

- `eventView`：只使用事件日收盘前已公开的数据，用于解释当时的选择；
- `currentView`：使用最新筹码和事件后行情，用于判断当前状态。

公告日、筹码快照日或财务数据发布日期晚于事件日时，不得进入`eventView`。
