# 回测规范

## 无前视偏差

- 交易日`t`只使用当时已公开数据。
- 前一晚模型不得使用`t`日涨幅和`t`日换手。
- 收盘确认模型可使用`t`日数据，但只能预测`t+1`以后。
- 分别报告次日、未来3日、未来5日触及涨停及收盘涨停。
- 创业板、科创板按20%制度判断，处理历史ST、停牌和制度变化。

## 样本与去重

- 至少60个有效交易日；
- 报告退市、停牌、无报价和抓取失败；
- 默认使用10个交易日冷却期，同时报告未去重结果；
- 历史市值若用当前截面代理，明确幸存者偏差。

## 基准

至少比较：

1. 同股票池全部股票日；
2. 同市值分组；
3. 创业板与科创板；
4. MA60下方股票日；
5. 当日涨幅小于5%的同类股票日。

报告信号数、命中数、命中率、基准率、提升倍数、信号后最差收益及门槛敏感性。

## 已知警示

- 重复放量下跌单因子未证明次数越多胜率越高。
- 极高分可能对应极端崩跌，命中率不保证单调。
- “当日涨幅大于5%后次日概率降低”是待检验假设，不写成事实。
- 形态样本不能因公司事件、基本面或事后涨跌被删除；否则产生选择偏差。外部事件单列标签。

只有完成时间外、股票外验证及概率校准后，才输出“估计概率”和置信区间。
