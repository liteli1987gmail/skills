# 因子定义与评分

## 输入字段

每只股票使用以下字段：

| 字段 | 定义 |
|---|---|
| `floatMarketCapYi` | 流通市值，亿元 |
| `twoDayLossPct` | 两个目标下跌日累计涨跌幅，百分数 |
| `selloffAmountRatio` | 目标杀跌日平均成交额÷此前基准期平均成交额 |
| `contractionRatio` | 杀跌后6日平均成交额÷目标杀跌日平均成交额 |
| `reboundPct` | 杀跌结束日至评分日前一日的累计涨跌幅 |
| `ma60GapPct` | 收盘价÷MA60-1，百分数 |
| `turnoverUplift` | 当日换手率÷此前6日平均换手率 |
| `currentChangePct` | 评分日涨跌幅 |
| `repeatedSelloffCount` | 最近60日聚类后的放量大跌事件数 |

默认使用前复权价格计算收益和均线，成交额不复权。

## 独立因子

### 中小流通市值

中心值45亿元，容忍宽度40亿元。它描述资金推动难度，不代表小盘股一定更好。

### 适度超跌

两日累计跌幅中心值-6%，容忍宽度5个百分点。极端崩跌可能对应基本面或流动性风险。

### 杀跌成交额放大

中心值1.7倍，容忍宽度1.2倍。成交额而非成交量作为默认口径。

### 后续缩量

中心值0.60，容忍宽度0.45。缩量必须与价格不再创新低共同解释。

### 价格止跌

杀跌后修复中心值3%，容忍宽度8个百分点。补充检查收盘是否站上MA5、MA10。

### MA60偏离

中心值-13%，容忍宽度12个百分点。深度超跌是位置描述，不是反转确认。

### 换手抬升

用当日换手率相对前6日平均值衡量。低于0.7不计分，2倍附近计满。

### 当日价格强度

将当日涨幅作为资金/题材响应的代理变量。它属于盘中或盘后确认因子，不能用于前一晚预测。

### 重复放量下跌

默认事件条件：

- 当日涨幅不高于-3%；
- 当日成交额高于此前两个交易日；
- 相隔不超过两个交易日的连续事件合并，保留跌幅更大的事件；
- 统计最近60个交易日。

按次数单调计分，7次封顶：

`15 × min(次数, 7) ÷ 7`

该分数衡量图片形态相似度。回测未证明次数越多真实涨停率越高，报告中必须保留此限制。

## 综合评分

基础八因子原始权重合计100：

- 流通市值12
- 两日跌幅12
- 杀跌放量15
- 后续缩量15
- 价格止跌10
- MA60偏离8
- 换手抬升13
- 当日价格强度15

加入重复放量下跌后：

`综合匹配分 = 基础八因子分 × 0.85 + 重复放量下跌分`

综合分衡量条件共识，不是校准概率。

## 题材催化层

题材不直接写入确定性数值，单列为：

- 已核验：公告、公司互动、行业事件或明确板块联动支持；
- 部分核验：公司存在相关业务，但当日驱动尚不能确认；
- 未核验：仅有市场传言或单一二手来源；
- 冲突：题材叙事与收入、利润或公告进展不一致。

只有“已核验”或“部分核验且出现板块联动”才可作为候选提升理由。
