# A股涨停概率因子研究

## 核心边界

- 将输出称为“形态匹配分”或“相对潜力排序”，除非完成样本外校准，不称为真实涨停概率。
- 不把截图中的自定义指标当作已知公式；只使用可从日线、成交额和可靠公开来源复算的字段。
- 不给出可直接执行的个性化买卖指令。
- 涉及当日行情、龙虎榜、公告或题材时，重新查询并标明数据截止时间。
- 始终使用公司全称和证券代码进行标的消歧。

## 工作流

1. 明确预测时点、观察窗口、股票池和结果窗口。默认观察60个交易日，结果窗口分别报告次日、未来3日和未来5日。
2. 若有截图，先保存原图并提取可见日期、价格、成交额、涨跌幅、换手率；无法辨认的字段标为未知。
3. 读取 [references/factors.md](references/factors.md)，逐项计算基础因子。
4. 对重复放量下跌事件进行聚类：跌幅不高于阈值且成交额高于此前两个交易日；相隔不超过两个交易日的事件合并。
5. 使用 `scripts/score_candidates.mjs` 生成确定性的匹配分。不要手工改变权重而不披露。
6. 读取 [references/backtest.md](references/backtest.md)，完成无前视偏差的滚动回测和基准比较。
7. 单独核验题材、公告与龙虎榜。将这些信息作为条件层，不用未经核验的“小作文”填充分数。
8. 输出因子明细、综合共识、反例、失效条件和观察清单。

## 综合共识

优先研究以下组合，而非任一单因子：

> 中小流通市值 + 适度超跌 + 杀跌成交额放大 + 随后缩量 + 多轮放量下跌释放 + 价格止跌 + 当日换手抬升 + 可核验题材催化。

解释顺序：

1. 放量下跌说明筹码集中交换，不等于吸筹。
2. 后续缩量且不再创新低，才说明边际卖压可能下降。
3. 价格站回短期均线和换手抬升，提供资金重新进攻的确认。
4. 题材或公告决定形态是否获得当日资金选择。
5. 龙虎榜只能描述席位行为，不能单独证明次日涨停。

重复放量下跌次数按用户确认的规则单调加分：次数越多，形态匹配越高；1—2次也保留部分分数；7次封顶。必须同时提示，历史检验尚未证明次数与真实涨停率单调正相关。

## 输出要求

至少包含：

- 数据日期、股票池、复权方式和阈值；
- 公司全称、代码、总分及各因子原始值；
- 已涨停与未涨停分组；
- 形态匹配分和真实概率的区别；
- 题材催化的来源与日期；
- 回测信号数、命中数、命中率、基准率和提升倍数；
- 至少一个不支持结论的反例；
- 次日需要验证的竞价、换手、板块联动和失效条件。
