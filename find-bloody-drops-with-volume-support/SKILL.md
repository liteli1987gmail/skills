# 寻找流血多血包多

## 核心原则

优先使用便利、稳定、能覆盖完整股票池的数据，不为初筛强制追求逐笔成交精度。

同一只股票、同一次扫描必须统一成交额口径。不得把真实成交额、VWAP成交额和代理成交额混合进同一时间窗口。

数据优先级：

1. 行情源直接返回的历史成交额。
2. `OHLC4 × 成交量`，其中 `OHLC4=(开盘+最高+最低+收盘)/4`。
3. `收盘价 × 成交量`。

结果接近阈值5%以内时，尝试用更精确数据复核；无法便利获取时保留并标记为边缘样本。

## 执行流程

1. 确认目标板块、总市值上限、两个目标日期和模型。
2. 校验日期是否为交易日。自然日休市时，明确说明并使用用户接受的相邻交易日；不得静默替换。
3. 建立完整股票池：
   - 创业板：300、301。
   - 科创板：688。
   - 主板：000、001、002、600、601、603、605。
4. 获取前复权日线，至少覆盖目标日前15个交易日及目标日后5个交易日。
5. 运行 `scripts/scan-volume-retreat.js`；优先复用缓存，缺少缓存时从便利行情接口批量获取。
6. 同时报告原始匹配数和强化匹配数。不得只展示人为缩小后的名单而隐去原始样本规模。
7. 输出数据截止日、日期窗口、成交额来源、公式、阈值和边缘样本。

## 模型选择

### 局部相对放量

默认模型。计算：

```text
A = 两个目标交易日成交额均值
B = 第一个目标日前15个交易日成交额均值
C = 第一个目标日前5日与第二个目标日后5日的成交额均值
```

原始条件：

```text
两个目标日均下跌
B > A > C
```

强化条件默认增加：

```text
两日累计跌幅 <= -8%
A / C >= 1.20
B / A >= 1.50
```

### 放量杀跌

用于“天铁科技模式”。分别对每个下跌日计算此前15个交易日中上涨日的成交额均值，要求下跌日成交额高于该均值。连续下跌至少两日，另行标记成交额递增、稳定或递减。

不要混淆两个模型：局部相对放量要求目标均额低于长期均额；放量杀跌可能要求下跌成交额高于上涨日均额。

## 输出规范

固定输出：

- 名称、证券代码、板块、总市值。
- 数据截止时间和目标日期。
- 每个目标日的收盘价、涨跌幅和成交额。
- 前15日总额、前15日均额、目标日均额、周边10日均额。
- `A/C`与`B/A`。
- 原始/强化/边缘状态。
- 成交额来源：`actual`、`vwap`、`ohlc4_proxy`或`close_proxy`。

公司事项、行业、实控人风险不得作为技术形态的预先剔除条件；可以单独增加风险标签。结果是研究候选，不是直接买卖指令。
